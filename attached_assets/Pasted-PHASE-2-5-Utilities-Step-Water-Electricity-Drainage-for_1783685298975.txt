PHASE 2.5 — Utilities Step (Water, Electricity, Drainage) for Kitchen Designer Tool

SAFETY RULES (CRITICAL):
- Do NOT modify, delete, or refactor ANY existing platform files (main platform, old Design Studio, quotes, auth, routes, database).
- Only create/edit files belonging to the kitchen designer tool (/kitchen-designer route, its components and its Zustand store).
- Do not change versions of any installed packages.
- Create a checkpoint when done.

CONTEXT:
The kitchen designer flow currently is: intro → 4 question cards → wall dimensions → openings (doors/windows on the 2D SVG architectural plan) → [placeholder 3D step]. This phase adds a NEW step "المرافق" (Utilities) BETWEEN the openings step and the 3D step. It reuses the SAME 2D SVG architectural plan component/style already built in the openings step (same walls, same real openings shown, same RTL Arabic UI, same visual language).

GOAL — CUSTOMER EASE IS THE TOP PRIORITY:
This step must be 100% OPTIONAL and effortless. A customer who knows nothing about plumbing must never feel blocked. Smart defaults everywhere, no required fields, one-tap removal, and a clear "تخطي هذه الخطوة" (skip) button.

UTILITY TYPES (all optional, stored in the kitchen designer Zustand store):

1. WATER SUPPLY (تغذية المياه) — max ONE:
   - Placed on a WALL. Customer taps a wall (or drags the icon onto a wall), the icon snaps to the wall and slides along it with live distance-from-corner measurement (like openings behave).
   - Icon: faucet symbol in a blue circle (like IKEA). Store: wallId + position along wall. Default height from floor: 55cm (hidden default, no field shown unless customer opens "تفاصيل").

2. ELECTRICITY (الكهرباء) — multiple allowed, two kinds:
   - فيش كهرباء (power outlet) — default height 30cm from floor (kitchen counter outlets can be edited later; keep it simple now).
   - مفتاح إضاءة (light switch) — default height 110cm from floor.
   - Both placed on WALLS, same drag/slide interaction with live measurements. Icons: simple clear symbols (outlet = circle with two dots, switch = small square with line), each in a distinct color chip so they're easy to tell apart.

3. DRAINAGE (التصريف) — multiple allowed, two kinds:
   - FLOOR drain: a circle symbol placed ANYWHERE on the floor area of the plan (free 2D drag inside the room), with live X/Y distance measurements from the two nearest walls while dragging.
   - WALL drain: placed on a wall like the others. Default height 40cm.

INTERACTION RULES (keep it effortless):
- A small toolbar/palette on the side of the plan with 4 big friendly buttons (Arabic labels + icons): تغذية مياه، فيش كهرباء، مفتاح إضاءة، تصريف. Tapping one enters "placement mode": the customer then taps/drag on a wall (or floor for drain) to drop it. For drain, after tapping التصريف show a tiny inline choice: "أرضية أم جدار؟" (two buttons).
- Every placed item: tap to select → shows live measurements + a delete (سلة) button + drag to reposition. Exactly the same feel as the openings step.
- Water supply button disables after one is placed (with tooltip "يمكن إضافة تغذية واحدة").
- Nothing is required. Prominent secondary button: "تخطي هذه الخطوة" goes to next step. Primary button: "التالي".
- Short friendly helper text at top: "حدد أماكن المياه والكهرباء والتصريف إن وجدت — يمكنك تخطي هذه الخطوة".
