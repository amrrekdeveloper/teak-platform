Task V2-001C — Architectural Room Shell and Visual Baseline

The current V2 isolation, geometry model, persistence, and tests are accepted.

However, the empty-room preview is not visually acceptable and must not be used as the foundation for openings, utilities, cabinets, or appliances yet.

Do not proceed to later stages.

Primary objective

Upgrade the existing V2 empty-room preview from a basic geometry proof into a visually credible architectural room shell that can serve as the baseline for the kitchen designer.

This task must preserve the current RoomV2 geometry model, persistence key, routes, and tests.

Do not replace the geometry model unless a narrowly scoped rendering adapter is necessary.

Required visual baseline

1. Room framing
- The room must fill most of the viewport on first load.
- Use automatic bounding-box-based camera framing.
- Default to a human-height interior perspective.
- Add a true top view.
- Remove excessive empty whitespace.
- Reframe automatically when room dimensions or layout change.

2. Architectural walls
- Render walls with visible thickness.
- Keep clean 90-degree corners.
- Use physically plausible wall height and thickness.
- Use a matte PBR wall finish.
- Preserve wall IDs and inward normals.
- Visual thickness must not alter the canonical room dimensions used by the design engine.

3. Floor
- Render a continuous floor plane or polygon derived from RoomV2.
- Add correct physical texture repetition.
- Add subtle PBR roughness and normal detail.
- Include at least:
  - beige porcelain 600 x 600 mm
  - light oak plank 180 x 1200 mm
- Ensure the material scale is clearly visible from the default camera.

4. Skirting
- Add a simple architectural skirting/baseboard around interior wall-floor intersections.
- Use a small realistic height.
- Keep it visual only and exclude it from collision geometry.
- It should update automatically with the generated room layout.

5. Ceiling
- Add a visible flat ceiling option.
- Add one experimental gypsum-board ceiling preset:
  - simple recessed perimeter
  - subtle cove lighting
  - a small number of recessed downlights
- Keep ceiling geometry separate from canonical wall/floor collision data.
- Allow toggling ceiling visibility for inspection.

6. Lighting
- Add balanced ambient/environment lighting.
- Add soft key lighting.
- Add subtle fill lighting.
- Enable shadows.
- Add optional warm recessed downlights.
- Add a simple warm indirect cove-light effect for the gypsum preset.
- Avoid overexposure and flat gray shading.

7. Rendering quality
- Use physically correct lighting where compatible with the current renderer.
- Use sRGB color handling.
- Use tone mapping and exposure suitable for interior visualization.
- Use soft shadows.
- Add subtle edge bevels only where needed for visual realism.
- Do not add heavy post-processing libraries unless already available.
- Avoid broad dependency upgrades.

8. Material system
- Keep the current typed material registry.
- Extend it to support:
  - base color
  - roughness
  - normal map
  - AO map
  - physical width and height
  - finish type
- Use lightweight local generated or placeholder maps for now.
- Do not download large paid texture packs.
- Do not add external paid services.

9. View controls
- Provide:
  - perspective view
  - top view
  - ceiling visibility
  - gypsum ceiling preset on/off
  - wall material selector
  - floor material selector
- Keep the controls clean and secondary to the room preview.

10. Performance
- Maintain acceptable performance on desktop and mobile.
- Avoid unnecessarily high texture resolution.
- Do not load all future materials.
- Use only the small proof material set.

Strict exclusions

Do not implement:
- doors
- windows
- service points
- cabinets
- appliances
- countertops
- backsplash editor
- quotations
- orders
- backend persistence
- database migrations
- deployment
- V1 changes

Acceptance criteria

The task is not complete unless:

- the room fills the viewport,
- the default view feels like standing inside a real room,
- wall surfaces are visibly matte and not flat unlit planes,
- the porcelain tile scale is visually understandable,
- the oak planks show realistic repeated dimensions,
- skirting is visible,
- the ceiling is visible,
- the gypsum ceiling preset is visually distinguishable,
- recessed lights and cove lighting are visible,
- shadows are present,
- the room remains correct for all four layouts,
- V1 behavior remains unchanged,
- the existing 15 geometry tests still pass,
- no new type errors are introduced.
