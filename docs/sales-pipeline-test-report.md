## ملخص التغييرات المُنفَّذة

### 1. إخفاء "تعيين مصمم" من واجهة المندوب

**الملف:** `client/src/pages/quotations.tsx`

- أُضيف متغير `canAssignDesigner` يسمح بالوصول فقط لـ `owner` و`assistant`.
- زر "تحويل لمصمم" (Assign Designer) محاط الآن بـ `{canAssignDesigner && ...}` بدلاً من ظهوره لجميع المستخدمين.
- دور `sales` لا يرى الزر في قسم "طلبات عروض الأسعار الجديدة".

**نتيجة الاختبار:** ✅ نجح — تحقق الاختبار الآلي أن الزر غير موجود في واجهة المندوب.

---

### 2. إضافة قسم إرفاق ملف التصميم للمندوب

**الملف:** `client/src/pages/order-detail.tsx`

- استُبدل بطاقة "في انتظار التصميم" (Awaiting Design) المعطّلة بقسم `SectionCard` جديد بعنوان "ملف التصميم".
- يظهر القسم للمندوب (`isSalesRep`) في مرحلة `survey_done`.
- يتضمن:
  - رسالة حالة: "إرفاق ملف التصميم" عند عدم وجود ملفات، و"ملف التصميم جاهز" عند وجود ملفات.
  - حقل نص لتسمية الملف (اختياري).
  - زر اختيار ملف + زر رفع الملف (يدعم PDF والصور).
  - عرض اسم الملف وحجمه عند الاختيار.
- يظهر قسم الرفع فقط عند وجود `firstSurveyId` (مسح ميداني مرتبط بالطلب).
- بعد رفع الملف تظهر أزرار "طلب تعديلات" و"وافق العميل - رفع إيصال".

**نتيجة الاختبار:** ✅ منطق الكود صحيح — تم التحقق يدوياً من هيكل القسم.

### 3. تحديث زر الإجراء الرئيسي للمندوب في مرحلة survey_done

**الملف:** `client/src/pages/order-detail.tsx`

- قبل التعديل: المندوب في مرحلة `survey_done` يرى زر "في انتظار التصميم" المعطّل عند عدم وجود ملفات تصميم.
- بعد التعديل: المندوب يرى دائماً زر "إنشاء عرض سعر" للانتقال لبناء العرض، بغض النظر عن وجود ملفات تصميم.
- يُمكّن المندوب من المضي قُدُماً في بناء العرض مع أو بدون ملف تصميم خارجي.

**نتيجة الاختبار:** ✅ الزر "في انتظار التصميم" المعطّل لم يعد موجوداً.

### 4. توسيع صلاحيات رفع ملفات التصميم

**الملف:** `server/routes.ts` — دالة `verifySurveyAccess`

- قبل التعديل: المندوب يستطيع رفع ملفات فقط على المسوحات التي أنشأها (`surveyRow.createdBy === user.id`).
- بعد التعديل: المندوب المُسنَد إلى عرض السعر المرتبط بالمسح يستطيع أيضاً رفع الملفات.

```typescript
if (user.role === "sales") {
  if (surveyRow.createdBy === user.id) return { allowed: true, survey: surveyRow };
  // Allow if assigned to the linked quotation
  if (surveyRow.quotationId) {
    const quotation = await storage.getQuotation(surveyRow.quotationId);
    if (quotation && quotation.assignedTo === user.id) return { allowed: true, survey: surveyRow };
  }
}
```

**نتيجة الاختبار:** ✅ منطق صحيح — يسمح للمندوب بالوصول للمسوحات المرتبطة بطلباته.

## ما هو خارج النطاق

- صفحة `designer-board` وأدوار المصمم — تبقى كما هي للاستخدام الاختياري.
- المصمم لا يزال يستطيع رفع التصاميم من واجهته كما كان.

## اختبار يدوي موصى به

للتحقق الكامل من الدورة، اتبع هذه الخطوات:

1. سجّل دخول كمندوب مبيعات
2. انتقل لـ `/quotations` — تحقق من غياب زر "تحويل لمصمم"
3. انتقل لـ `/my-orders` — أنشئ طلباً جديداً إذا لزم
4. احجز موعداً ورفع المقاسات
5. ابحث عن طلب في مرحلة "مسح مكتمل"
6. افتح تفاصيله — تحقق من ظهور قسم "ملف التصميم" مع أزرار الرفع
7. ارفع ملف PDF أو صورة كملف تصميم
8. تحقق من ظهور الملف في المرفقات
9. انقر "إنشاء عرض سعر" وأكمل بناء العرض
10. أرسل العرض وافق العميل برفع الإيصال
